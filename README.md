# ComputeX 算力租赁平台

> 依据《PRD-算力租赁平台.md》(V2.0 旗舰版) 实现的完整可运行产品演示版
> 技术栈：Node.js 24 + Express + 内置 SQLite（零编译依赖） | React 18 + Vite + Ant Design 5

## 快速启动

```bash
# 1. 启动后端（端口 8787）
cd compute-x/server
node src/index.js

# 2. 启动前端（端口 5173）
cd compute-x/web
npm run dev
```

浏览器访问 **http://localhost:5173**

## 功能覆盖（对照 PRD）

### 需求方控制台（/console）
- **概览**：本月消费、实例状态、预算进度、30 天消费趋势、状态分布、资源利用率
- **资源市场**：GPU/地域/价格/状态多维筛选、基准分排序、资源详情（实测基准分/健康分/资源方评分）、3 资源对比、降价订阅、成本估算器（任务类型×卡数×时长）
- **创建实例**：4 步向导（选资源→配置→项目与审批→确认支付），右侧实时费用估算，超预算拦截，超阈值自动触发审批
- **实例管理**：状态筛选/批量操作、完整状态机（创建中→运行中→已停止→释放中→已释放、异常、待续费、被回收）、监控曲线（GPU/显存/CPU/内存）、SSH 连接、日志、告警、快照、计费明细
- **账单与发票**：账期账单、按实例聚合明细、余额支付、充值、开票申请（普票/专票）与进度推进、争议工单
- **组织与项目**：成员邀请/禁用/离职交接、项目预算与审批阈值、审计日志（操作留痕）
- **审批中心**：实例购买/预算申请审批，通过后自动扣费交付（多端同步）
- **工单中心**：六类工单、SLA 首次响应时限、回复流转、计费争议自动关联
- **消息中心**：告警/审批/账单/系统分类、未读标记、跳转对应详情页
- **设置**：账号安全、通知偏好（关键告警不可退订）、API 密钥与 Webhook

### 资源方后台（/provider）
- 收益概览（结算收益/利用率/趋势）、库存监控
- 资源管理：上架/下架、实时调价、健康分
- 订单与结算：T+7 结算、平台佣金 7%、提现（最低 100 元）
- 工单协同：平台派单接单、SLA 计时
- 账户与资质：保证金、资质认证状态

### 平台管理后台（/admin）
- 平台概览：GMV 趋势、企业/资源方数、治理红线提示
- 资源方审核：通过/驳回/停用（含保证金与费率）
- 市场管理：全市场资源上下架
- 企业管理、订单管理、账单与供给方结算（平台佣金差异化）、工单售后 SLA
- 系统公告发布（推送到全体用户）

### 移动端 App（/app，手机壳模拟）
- 底部 4 Tab：工作台（费用/实例/待办/告警概览）、实例（启停/续费/释放）、账单（支付/明细）、我的（成员/审批/帮助）
- 消息中心（分类+未读）、审批处理、新建工单
- 危险操作二次确认（输入实例名）

## 核心业务链路（已自动化验证）

```
登录 → 浏览资源（筛选/对比/估算）
  → 4 步下单 → [超阈值自动进入审批] → 支付（余额）→ 实例创建中 → 2s 交付 → SSH 可登录
  → 运行计费（按秒计量/按小时出账）→ 启停/快照/续费/监控告警
  → 释放 → 数据擦除（NIST 800-88）→ 账单出账 → 开票/支付 → 工单售后
  → 平台与资源方 T+7 结算（佣金 7%）
```

```
│   │   └── routes/          # auth / market / orders / billing / org / tickets / notifications / provider / admin / dashboard
│   └── data/computex.db     # SQLite 数据库（自动生成）
└── web/                     # React + Vite + Ant Design
    └── src/
        ├── pages/Login.jsx  # 一键登录（演示账号）
        ├── console/         # 需求方控制台（18 个页面）
        ├── provider/        # 资源方后台
        ├── admin/           # 平台管理后台
        ├── app/             # 移动端 App（4 Tab + 二级页）
        └── components/      # 自绘 SVG 图表（零额外依赖）
```

## 已知限制（演示版）

- 实例交付为模拟（下单后约 2 秒进入运行中），未对接真实 GPU 资源
- 监控/日志数据为模拟生成；支付仅余额扣减，未接第三方支付
- 竞价实例、SSO/企业微信登录、OpenAPI 文档站为 M2 范围（演示版提供 API 密钥管理入口）
- 权限矩阵按 PRD 7.4.1 核心角色落地，财务/只读成员部分操作以界面提示代替拦截
