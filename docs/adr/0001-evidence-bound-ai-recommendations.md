# ADR 0001：AI 推荐受业务证据约束

- 状态：接受
- 日期：2026-08-26

## 背景

ComputeX V3 需要让用户用自然语言描述算力需求，并得到可直接进入预算校验、审批和下单流程的推荐方案。大语言模型擅长理解和解释需求，但不能作为库存、价格、基准性能或审批结论的事实来源。

## 决策

工作负载解析、资源筛选、费用测算、预算校验和排序由确定性的业务服务完成，并保存报价快照。大语言模型仅在配置可用时负责把结构化结果解释成人可读建议；模型不可创建数据库中不存在的资源，也不可覆盖确定性计算结果。

任何推荐或优化机会只能生成订单草稿，必须经过用户确认和适用的企业审批策略，才能成为订单或资源操作。

## 后果

- 同一输入和同一报价快照可复算、可测试、可审计。
- 模型不可用时核心推荐仍可工作，但界面会明确标记为规则引擎解释。
- 推荐结果需要记录证据、计算版本和报价时间。
- AI 提示词和模型升级不会改变交易事实。
